# Sushree Elina Sahoo — Animated React Portfolio

Responsive portfolio built with React, Vite, Tailwind CSS, Lucide icons, and custom CSS animations.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Personalize before publishing

- Replace `public/elina.png` with your preferred transparent-background portrait (keep the filename).
- In `src/components/Contact.jsx`, replace `your-email@example.com` with your email.
- Check your LinkedIn and GitHub URLs in `Home.jsx` and `Contact.jsx`.
- Update education details, years, training dates, certificates, and project repository links with verified information.
- To add a resume download, place your PDF at `public/resume.pdf` and add a link with `href="/resume.pdf" download`.

The content uses project and education details supplied in the conversation. Please verify all details before publishing.
